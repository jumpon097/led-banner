แจ้งเตือน

วิธีนำขึ้น GitHub Pages แจกเพื่อนฟรี

1
สร้าง Repository บน GitHub ล็อกอิน GitHub แล้วกด New repository ตั้งชื่อ เช่น led-banner (เลือกเป็น Public)
2
อัปโหลดไฟล์ index.html กด Add file > Upload files ลากไฟล์ index.html นี้ขึ้นไป แล้วกด Commit changes (ใช้แค่ไฟล์เดียวจบเลย!)
3
เปิดใช้งาน GitHub Pages ไปที่แท็บ Settings > Pages ตรงหัวข้อ Build and deployment เลือก Branch เป็น main หรือ master แล้วกด Save
